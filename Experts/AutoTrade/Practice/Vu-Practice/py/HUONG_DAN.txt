===========================================================
  1. CAC FILE CHINH
===========================================================

  gen_input_ini.py
    Doc file EA (.mq5), phan tich cac tham so input,
    roi sinh ra file input.ini de auto_optimize dung.

  auto_optimize_multisymbol.py
    Doc input.ini -> inject code vao EA -> compile ->
    chay optimize tren MT5 -> thu thap ket qua -> xuat CSV/XLSX.
    Ho tro nhieu MT5 terminal chay song song.

  input.ini
    File cau hinh chinh, gom 4 section:
      [Symbols]       -- danh sach symbol va suffix (vd: "m" cho Exness micro)
      [Tester]        -- cau hinh backtest (deposit, date, model...)
      [MT5]           -- hash terminal + duong dan terminal64.exe
      [TesterInputs]  -- tham so input cua EA voi range optimize

  state.txt
    Luu danh sach cac job (symbol_period) con lai.
    Tu dong tao khi chay. Neu bi tat giua chung, chay lai
    se tu resume tu day.

  mt5_paths.ini
    Luu hash + path MT5 tu lan cau hinh dau tien.
    Dung khi input.ini khong co [MT5] section.


===========================================================
  2. GIAI THICH TUNG HAM -- gen_input_ini.py
===========================================================

  find_includes(mq5_text, base_dir)
    Quet source code EA tim cac dong #include "file.mqh"
    (dang dau nhay kep -- file cuc bo, khong phai thu vien MT5).
    Tra ve list duong dan file include ton tai tren o dia.

  collect_source(mq5_path)
    Gom toan bo source code: doc file .mq5 chinh, roi de quy
    doc them tat ca file #include cuc bo.
    Muc dich: dam bao parse duoc tham so input nam trong file header.

  parse_inputs(source)
    Dung regex de tim tat ca khai bao dang:
      input <type> <name> = <default>;   // comment tuy chon
    Tra ve list dict {name, type, default, comment}.

  is_separator(param)
    Nhan ra cac tham so "dai phan cach" trong EA (thuong la
    input string _sep = "==========";) -- nhung tham so nay
    khong co y nghia thuc, bi bo qua khi sinh input.ini.

  normalize_bool(val)
    Chuyen gia tri bool kieu MQL5 (true/false) sang so 0/1
    vi MT5 Strategy Tester chi nhan dang so.

  build_tester_input_line(param)
    Sinh 1 dong [TesterInputs] theo format MT5:
      TenParam=value||value||step||stop||N
    Mac dinh N (khong optimize). Nguoi dung tu doi Y va dien range.

  relative_expert_path(mq5_path)
    Tinh duong dan EA tuong doi tu thu muc MQL5 de ghi vao
    [Tester] expert= trong input.ini.
    Vi du: AutoTrade\Practice\MyEA.ex5
    (MT5 tu prepend "Experts\" nen khong can ghi lai)

  detect_mt5_terminals()
    Quet %APPDATA%\MetaQuotes\Terminal\ de tim tat ca
    MT5 terminal da cai. Xac nhan bang su ton tai cua
    origin.txt va thu muc MQL5.
    Tra ve list {hash, label, path}.

  find_mt5_program(terminal_folder)
    Doc origin.txt cua terminal de tim duong dan terminal64.exe.
    Fallback ve C:\Program Files\MetaTrader 5\terminal64.exe.

  select_mt5_terminal()
    Hoi nguoi dung chon 1 hoac nhieu terminal (hoac tat ca).
    Tra ve list [(hash, program_path)].
    Neu chi co 1 terminal -> tu chon khong can hoi.

  find_set_file(mq5_path, selected_terminals)
    Tim file .set cua EA trong thu muc MT5 Strategy Tester
    (MQL5\Profiles\Tester\EaName.set).
    File .set chua range optimize user da chinh tay trong MT5.

  read_set_file(set_path)
    Doc file .set (MT5 luu UTF-16 LE).
    Parse tung dong "Param=value||start||step||stop||Y/N"
    tra ve dict de dung thay cho gia tri mac dinh tu source code.

  generate_input_ini(mq5_path, output_path, selected_terminals)
    Ham chinh: doc EA -> parse inputs -> hoi chon terminal ->
    tim file .set -> ghi toan bo ra input.ini.
    Neu selected_terminals da truyen vao thi khong hoi lai
    (tranh hoi 2 lan khi goi tu interactive_mode).

  search_ea_on_windows(name)
    Tim file .mq5 theo ten tren toan may.
    Tim trong: tat ca MT5 terminal (MQL5\), Desktop,
    Documents, Downloads. So sanh ten khong phan biet hoa thuong.

  interactive_mode()
    Che do hoi thoai khi chay khong co argument:
      Buoc 1 -- Chon MT5 terminal
      Buoc 2 -- Hoi ten EA (hoac keo tha file)
      Buoc 3 -- Copy EA vao MQL5\Experts\ neu chua co
      Buoc 4 -- Goi generate_input_ini de sinh input.ini

  3. GIAI THICH TUNG HAM -- auto_optimize_multisymbol.py

  -- PHAN INJECT EQUITY REPORTER --

  EQUITY_BLOCK  (hang so chuoi)
    Toan bo doan code MQL5 se duoc chen vao EA.
    Gom: mang luu equity theo ngay, ham tinh custom Sharpe,
    ham dem gio trong trade, ham ghi CSV equity, ham ghi
    report.txt. Day la "bo do luong" duoc nhung vao EA.

  _inj_find_func_open_brace(source, pattern)
    Tim vi tri dau { mo dau cua mot ham (OnInit, OnTick...).
    Dung de biet cho nao chen lenh goi _er_OnInit() v.v.

  _inj_inject_after(source, brace_pos, code)
    Chen doan code ngay sau dau { tim duoc.

  _inj_insert_block(source)
    Chuan bi toan bo EQUITY_BLOCK truoc khi chen:
    - Doc input.ini de lay ten/gia tri tham so -> chen vao
      diem neo //--- INJECT_INPUTS_HERE --- trong block.
    - Them forward declarations len dau file (tranh loi compile).
    - Day toan bo EQUITY_BLOCK xuong cuoi file source.

  inject_ea(mq5_path, magic)
    Thuc hien inject vao file .mq5:
    - Chen _er_OnInit() vao trong OnInit()
    - Chen _er_OnTick() vao trong OnTick() hoac OnBar()
    - Chen _er_OnTester() vao trong OnTester()
      (hoac them ham OnTester() moi neu EA chua co)
    - Ghi ra file moi ten EA_XYZ.mq5
    EA goc KHONG bi thay doi.

  find_metaeditor_path(mt5_program_path)
    Tim metaeditor64.exe canh terminal64.exe.

  compile_mq5(metaeditor_path, mq5_path)
    Compile file EA_XYZ.mq5 bang MetaEditor.
    Cho toi da 30 giay cho .ex5 xuat hien.
    Tra ve True neu compile thanh cong.

  get_inject_magic(input_cfg)
    Doc magic number tu input.ini:
    - Uu tien [Tester] inject_magic
    - Fallback tim key "magic" trong [TesterInputs]
    Magic dung de loc dung position cua EA khi tinh equity.

  maybe_inject_and_compile(input_cfg, mt5_folder_path, mt5_program_path)
    Dieu phoi toan bo qua trinh inject + compile:
    - Tim file .mq5 tu [Tester] expert=
    - Luon xoa file EA_XYZ cu de ep inject code moi nhat
    - Goi inject_ea -> compile_mq5
    - Cap nhat [Tester] expert= thanh EA_XYZ.ex5

  convert_xml_to_xlsx(opt_report_path, target_path)
    Chuyen file XML report cua MT5 Strategy Tester
    sang file .xlsx (Excel) dung pandas.
    Xoa file XML goc sau khi convert.

  run_one_job(...)
    Worker chay trong 1 thread, xu ly 1 MT5 terminal.
    Lay job tu queue (symbol_period), chay lien tuc cho den het:
    - Tinh fromdate tu symbol_startyear neu fromdate=0
    - Ghi file config_{idx}.ini de truyen cho terminal MT5
    - Goi subprocess MT5 voi /config:...
    - Cho MT5 xong -> convert XML -> copy agent outputs
    - Cap nhat state.txt sau moi job hoan thanh
    - Neu khong co XML report -> dat stop_event -> cac thread khac cung dung

  run()
    Entry point cua toan bo tool:
    1. Kiem tra input.ini
    2. Hien thi + xac nhan
    3. Setup MT5 paths
    4. Inject + compile EA
    5. Hoi xoa state/reports cu
    6. Tao queue tu symbol x period
    7. Tao 1 thread per terminal -> chay run_one_job song song
    8. Cho tat ca thread xong -> in tong ket


===========================================================
  4. CO CHE HOAT DONG (pipeline dau den cuoi)
===========================================================

  BUOC A -- Sinh input.ini (gen_input_ini.py)
  -------------------------------------------
    1. Doc file EA.mq5 va tat ca #include cuc bo
    2. Dung biểu thức chính quy(Regex) tim tat ca khai bao "input <type> <name> = <value>;"
    3. Tim file .set trong MT5 Strategy Tester (neu co)
       -> Dung range optimize tu .set thay vi gia tri mac dinh
    4. Ghi input.ini voi 4 section: Symbols, Tester, MT5, TesterInputs

  BUOC B -- Inject equity reporter (auto_optimize_multisymbol.py)
  ---------------------------------------------------------------
    EA goc: MyEA.mq5
    |-> inject_ea()
    MyEA_XYZ.mq5  (EA goc + EQUITY_BLOCK duoc chen vao)
    |-> compile_mq5()
    MyEA_XYZ.ex5  (ready de chay trong MT5)

    Code duoc inject thuc hien 3 viec trong EA:
    - OnInit()  -> khoi tao mang equity, bien dem gio
    - OnTick()  -> moi tick: luu equity cuoi ngay, dem gio trong trade
    - OnTester()-> ket thuc backtest: ghi CSV equity + report.txt,
                   tra ve custom Sharpe ratio lam optimization criterion

  BUOC C -- Chay optimize song song
  ----------------------------------
    Moi terminal MT5 chay trong 1 thread rieng.
    Tat ca terminal lay job tu cung 1 queue.
    VD: 25 symbol x 2 period = 50 job, 2 terminal
    -> moi terminal chay ~25 job, tong thoi gian giam 50%.

    Flow moi job:
    1. Ghi config_{idx}.ini voi symbol/period cu the
    2. Goi terminal64.exe /config:config_{idx}.ini
    3. MT5 tu chay optimize -> luu ket qua vao:
       - reports\opt_SYMBOL_PERIOD_...xml       (optimization report)
       - Tester\{hash}\Agent-xx\MQL5\Files\     (equity CSV + report.txt)
    4. convert_xml_to_xlsx()  -> reports\*.xlsx
    5. copy_agent_outputs()   -> reports\agents\SYMBOL_PERIOD\*.csv
    6. Cap nhat state.txt (xoa job vua xong)

  BUOC D -- File output
  ----------------------
    reports\
      opt_EURUSD_H1_..._EBR.xlsx    <- bang optimization pass day du
      agents\
        EURUSD_H1\
          EA_EURUSD_H1_20260101_Pass1_equity_day.csv
          EA_EURUSD_H1_20260101_Pass2_equity_day.csv
          ...

    Moi file CSV trong agents co 3 section:
      Settings    -- EA name, symbol, period, thoi gian test, inputs
      Metric      -- custom_sharpe, profit, dd, trades, ...
      Daily Equity -- equity tung ngay trong backtest

  CO CHE RESUME
  -------------
    state.txt luu danh sach job chua hoan thanh.
    Khi tat tool giua chung, chay lai -> tool doc state.txt
    -> bo qua cac job da xong -> tiep tuc tu job con lai.
    Muon chay lai tu dau: chon YES khi tool hoi xoa state.txt.

===========================================================
  7. DINH DANG [TesterInputs]
===========================================================

  ParamName=value||value||step||stop||N    <- co dinh (khong optimize)
  ParamName=start||start||step||stop||Y    <- optimize

  Vi du:
    StopLoss=50||50||1||50||N              <- co dinh 50
    TakeProfit=100||50||10||200||Y         <- optimize tu 50 den 200, buoc 10

  Cot 1 -- gia tri hien tai (MT5 dung de hien thi)
  Cot 2 -- start (diem bat dau optimize)
  Cot 3 -- step  (buoc nhay)
  Cot 4 -- stop  (diem ket thuc)
  Cot 5 -- Y/N   (Y = optimize, N = co dinh)

  [Loi 1] can't open file '...\gen_input_ini.py': No such file or directory
  Nguyen nhan: Dang dung sai thu muc.
  Cach sua: cd vao thu muc py truoc, hoac dung duong dan day du.

  [Loi 2] Khong tim thay tham so input nao trong EA
  Nguyen nhan: EA khong co khai bao "input <type> <name> = <value>;"
  Cach sua: Kiem tra lai file .mq5 dung chua.

  [Loi 3] Khong tim thay file: ...
  Nguyen nhan: Duong dan EA sai.
  Cach sua: Ten co khoang trang phai boc dau nhay kep:
    python gen_input_ini.py "Moving Average.mq5"

  [Loi 4] Khong tim thay mt5_tester_path / mt5_folder_path
  Nguyen nhan: Hash terminal trong input.ini sai.
  Cach sua: Kiem tra [MT5] terminal_hash.
    Hash dung la ten thu muc trong: %APPDATA%\MetaQuotes\Terminal\

  [Loi 5] Khong thay XML report sau khi chay optimize
  Nguyen nhan: MT5 khong hoan thanh optimize (thieu data, sai symbol...).
  Cach sua:
    - Chay thu cong trong MT5 de kiem tra.
    - Kiem tra symbol + suffix co dung khong.
    - Tool dung lai, sua xong co the tiep tuc nho state.txt.

  [Loi 6] input.ini bi ghi de mat cau hinh cu
  Nguyen nhan: Chay gen_input_ini.py khi input.ini da co.
  Cach sua: Copy input.ini ra noi khac truoc khi chay lai.

  [Loi 7] [Inject] Compile FAIL -- khong tim thay .ex5
  Nguyen nhan: MetaEditor bao loi cu phap khi compile EA_XYZ.mq5.
  Cach sua:
    - Mo EA_XYZ.mq5 trong MetaEditor -> xem dong loi.
    - Thuong do EA goc co cu phap dac biet lam inject sai vi tri.
    - Xoa EA_XYZ.mq5 -> bao loi de duoc ho tro.

  [Loi 8] [Inject] Khong tim thay metaeditor64.exe
  Nguyen nhan: mt5_program_path sai hoac MetaTrader chua cai.
  Cach sua: Kiem tra [MT5] mt5_program_path tro dung den terminal64.exe.
    metaeditor64.exe phai nam cung thu muc voi terminal64.exe.

  [Loi 9] [Inject] EA khong co OnTick -- inject bo qua
  Nguyen nhan: EA khong co ham OnTick() hoac OnBar().
  Hau qua: Equity khong duoc ghi, report.txt se trong.
  Cach sua: EA phai co OnTick() hoac OnBar() de inject hoat dong.

  [Loi 10] PermissionError khi ghi EA_XYZ.mq5
  Nguyen nhan: File dang duoc mo trong MetaEditor.
  Cach sua: Dong file EA trong MetaEditor truoc khi chay.

  [Loi 11] Khong co file equity_day.csv trong agents\
  Nguyen nhan 1: Inject khong thanh cong (xem Loi 7, 9).
  Nguyen nhan 2: MT5 khong chay du optimize pass (0 ket qua).
  Cach sua: Xoa EA_XYZ.mq5 + EA_XYZ.ex5 -> chay lai.

  [Loi 12] custom_sharpe = 0 trong tat ca pass
  Nguyen nhan: EA khong co du du lieu equity (< 2 ngay).
  Cach sua: Mo rong khoang thoi gian backtest (fromdate/todate).
