-------------------------------------------------------------------
2. FILE STATE (2 file riêng biệt)
-------------------------------------------------------------------

ea_state.txt
  → Lưu danh sách EA chưa chạy
  → Mỗi dòng: <path_ea>|<magic>
  → Khi EA xong → xóa dòng đó ngay lập tức
  → File rỗng / không tồn tại = đã xong tất cả EA

state.txt  (giữ nguyên như cũ)
  → Lưu danh sách symbol_period chưa chạy của EA HIỆN TẠI
  → Khi chuyển sang EA mới → xóa state.txt cũ → tạo mới


-------------------------------------------------------------------
3. QUY TRÌNH CHẠY
-------------------------------------------------------------------

START
  │
  ├─ Đọc input.ini → hiển thị → xác nhận với user
  │
  ├─ Setup MT5 paths (giữ nguyên logic cũ)
  │
  ├─ Đọc ea_state.txt
  │     Nếu tồn tại  → resume từ EA còn lại
  │     Nếu không    → tạo mới từ [Experts] trong input.ini
  │
  └─ LOOP từng EA:
       │
       ├─ Lấy EA đầu tiên từ ea_state.txt
       │
       ├─ Inject → tạo EA_EBR.mq5
       │
       ├─ Compile → tạo EA_EBR.ex5
       │    Nếu FAIL → dừng, báo lỗi
       │
       ├─ Xóa ea_state.txt dòng EA này ngay (an toàn resume)
       │
       ├─ Tạo reports\<TênEA>\ subfolder
       │
       ├─ Xóa state.txt (symbols/TF của EA cũ)
       │
       ├─ Tạo state.txt mới cho EA này (toàn bộ symbol × TF)
       │
       ├─ LOOP từng symbol × TF: (logic hiện tại, giữ nguyên)
       │     → Launch MT5 /config:...
       │     → Copy CSV + TXT từ Agent → reports\<TênEA>\
       │     → Convert XML → XLSX → reports\<TênEA>\
       │     → Cập nhật state.txt (xóa job đã xong)
       │
       ├─ state.txt rỗng → EA này XONG
       │
       └─ Tiếp EA kế tiếp trong ea_state.txt
            ...
  │
  └─ ea_state.txt rỗng → TẤT CẢ XONG

5. RESUME KHI BỊ NGẮT GIỮA CHỪNG
-------------------------------------------------------------------

Trường hợp 1: Ngắt khi đang chạy EA2, giữa USDJPY_H1
  ea_state.txt còn: EA2, EA3
  state.txt còn: USDJPY_H1, CADJPY_H1, ...
  → Khởi động lại → tiếp tục EA2 từ USDJPY_H1 → xong → EA3

Trường hợp 2: Ngắt ngay khi vừa chuyển sang EA3
  ea_state.txt còn: EA3
  state.txt: không tồn tại (chưa tạo)
  → Khởi động lại → tạo state.txt mới cho EA3 → chạy từ đầu EA3

Trường hợp 3: EA2 lỗi compile
  → Dừng ngay, không xóa ea_state.txt
  → User fix EA2 → chạy lại → tiếp tục từ EA2


-------------------------------------------------------------------
6. THAY ĐỔI CODE CẦN LÀM
-------------------------------------------------------------------

Thêm mới:
  - read_experts_list(input_cfg)       → đọc [Experts], trả về list (path, magic)
  - build_ea_state(experts_list)       → tạo ea_state.txt
  - load_ea_state()                    → đọc ea_state.txt
  - pop_ea_from_state(ea)              → xóa EA đã lấy khỏi ea_state.txt
  - run_all_eas()                      → loop chính qua từng EA

Sửa:
  - run()                              → gọi run_all_eas() thay vì chạy thẳng
  - copy_agent_outputs()               → thêm tham số ea_name để copy vào subfolder EA
  - maybe_clear_state_and_reports()    → hỏi 1 lần trước khi bắt đầu toàn bộ

Giữ nguyên:
  - run_one_job()                      → không đổi
  - inject_ea(), compile_mq5()         → không đổi
  - convert_xml_to_xlsx()              → không đổi
